# Sales Performance Dashboard

Interactive Sales Dashboard created using Power BI and Excel for sales analysis and business insights.

## Tools Used
- Microsoft Excel
- Power BI

## Features
- KPI Cards
- Sales by Region Analysis
- Monthly Sales Trend
- Category Wise Sales
- Top 5 Products Analysis
- Interactive Slicer Filter

## Dashboard Insights
- Regional sales performance comparison
- Monthly sales trend visualization
- Product category analysis
- Top performing products identification
